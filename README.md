# 空竹频闪分解图工作台

从教学录像自动合成体育杂志式频闪分解图:时序众数背景估计 → 动作转折自动定位 → 软边抠图 → WebGL2 多层时序合成与统一调色。

## 启动

```bash
npm install
npm run dev      # 本地开发
npm test         # 16 项单元测试
npm run bench    # 1080p/60s 数据规模性能基准
npm run build    # 类型检查 + 生产构建
```

## 四个工作台页面

1. **录像导入** —— 拖入视频。WebCodecs + mp4box 解封装(主路径),WebM/老浏览器自动回退到 video 元素逐帧扫描;像素计算全部在 Web Worker。
2. **背景估计** —— 每像素 RGB332 时序众数 + 邻色均值精修 + 空间中值修复。持续移动的选手、路过行人、移动影子在任一像素都不占多数,不会进入背景;晃动树叶围绕真实叶色抖动,众数仍落在叶色。附背景覆盖率热力图检查残留。
3. **关键时刻挑选** —— 低分辨率全片扫描,按空竹运动学检测抛起最高点(垂直速度变号)、换手(越过双手中点/水平速度反转且水平分量占主导)、接住(近手距离局部极小+速度骤降),时间轴分桶保证全片均匀覆盖。可点帧增删、粘贴真值 JSON 评估帧差。
4. **分解图编辑** —— 软阈值背景差分抠图(高置信种子连通去噪,保留运动模糊半透明边与细线)、按帧号升序 over 合成(后一时刻必然压住前一时刻)、越早越淡、LUT 统一调色、画笔修边、PNG 导出。

## 数据集工作室(右上角)

纯 TypeScript 渲染 3 场地(公园/广场/体育馆)× 3 花样(抛接/换手/捞月)共 9 组带真值教学录像,含晃动树叶、漂移落叶、两名路过行人、移动影子和空竹运动模糊。每组输出:

- WebM 视频 + meta.json(事件真值 + 每帧二值蒙版 RLE)
- 背景残留率、关键时刻与真值帧差、抠图软/硬 IoU、端到端耗时

## 关键技术决策

| 需求 | 实现 |
| --- | --- |
| 背景不能留选手/行人/影子 | 逐像素时序众数(扁平定长直方图,无 Map 分配)+ 空间中值修复 |
| 空竹糊边、细线要保留 | 双阈值软 alpha + 形态学膨胀桥接 + 种子连通 flood fill |
| 遮挡顺序不乱 | 图层按 frameIndex 排序后依次 over 混合,顺序由数据保证 |
| 越早越淡 | 层不透明度在 `[earliestOpacity, 1]` 间按层序线性插值 |
| 20 秒预算 | 众数/抠图在 Worker,合成在 WebGL2;基准实测端到端约 9 秒 |

## 目录

```
src/core/        纯 TS 算法(可在 Node 单测):背景、抠图、事件检测、合成、解码、渲染器
src/core/pipeline.worker.ts   背景估计与抠图 Worker
src/webgl/       WebGL2 合成器
src/pages/       四个工作台页面 + 数据集工作室
test/            Vitest 单元测试(16)
bench/           1080p 性能基准
```

## 验收口径

- 背景残留率 < 2%(对合成数据干净真值背景逐像素色差统计,见 `test/dataset.test.ts`)
- 自动关键时刻与教练/真值事件帧差 ≤ 3(顶点、换手均有专项测试)
- 1 分钟 1080p、6 时刻端到端 < 20 秒(`npm run bench`,Node 纯算约 9 秒;浏览器 GL 合成更快)
- 抠图软 IoU > 0.6、硬 IoU > 0.5(含半透明运动模糊边)
